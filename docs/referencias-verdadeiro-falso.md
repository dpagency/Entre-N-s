# Referências para revisão das perguntas de Verdadeiro ou Falso — Entre Nós

Registro inicial em 20/10/2026. Estas fontes servirão para revisar enunciados, gabaritos e justificativas das perguntas V/F do jogo. A inclusão de uma referência não significa validação automática de uma resposta; cada afirmação deve ser conferida em seu contexto e, quando normativa, no texto vigente aplicável.

## Uso na revisão

- Relacionar cada pergunta à referência pertinente.
- Verificar se o enunciado é inequívoco e se o gabarito está correto.
- Registrar uma justificativa breve, acessível ao jogador.
- Distinguir materiais de sensibilização de normas vinculantes.
- Conferir a vigência e a aplicabilidade de normas antes de fundamentar respostas.
